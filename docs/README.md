# Sales and teaching material

Material for showing the framework to someone who has not seen it, and for walking a new
owner through their first fortnight with it.

| File | What it is | Who it is for |
|---|---|---|
| `Personal AI Assistant — Installation.pptx` | Eighteen slides for a room with laptops open: what everyone walks out with, why the architecture is written for agents rather than for people, Obsidian and what skipping it costs, then seven numbered do-it-now steps — vault, project, the sentence, the dashboard, your departments, a skill, a specialist — with a checkpoint after each | Running a live workshop. This is the one to present |
| `START HERE.md` | The twenty-minute walkthrough: make a folder, connect it in Claude, ask for the setup in plain words, name your departments. No terminal, no Python, nothing to install | The person who just bought it and has never opened a command line |
| `The AI Operations Framework — a step-by-step start.pptx` | Fourteen slides in MeshPro's own colours and type: where a company's facts actually live today, the four ideas, the twenty-minute setup with no terminal in it, departments first, and what the generated page says on day one and a fortnight later | Someone deciding whether to adopt it, and someone who has just installed it |
| `…same name….pdf` | The same deck, exported. Use it when presenting from a machine without **Public Sans** installed — PowerPoint will substitute a different typeface and the layout will shift slightly | Presenting from somebody else's laptop |

The deck is built to be presented, not read alone — every slide carries speaker notes.

It is set in **Public Sans** (free, Google Fonts) on MeshPro violet `#7367F0` and navy `#15171F`, per
the MeshPro Brand Guide v1.0. Install Public Sans on the machine you present from, or use the PDF.

The screenshots in it come from a vault created by running `install.py` against an empty folder,
then left alone for a fortnight so the check had something true to complain about. Nothing in
them is from a real company's vault.
