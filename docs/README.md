# Sales and teaching material

Material for showing the framework to someone who has not seen it, and for walking a new
owner through their first fortnight with it.

| File | What it is | Who it is for |
|---|---|---|
| `The Operations Framework — a step-by-step start.pptx` | Fourteen slides: the four ideas, what the install puts on disk, and a day-by-day first fortnight with screenshots of the real page the framework generates | Someone deciding whether to adopt it, and someone who has just installed it |

The deck is built to be presented, not read alone — every slide carries speaker notes.

The screenshots in it come from a vault created by running `install.py` against an empty folder,
then left alone for a fortnight so the check had something true to complain about. Nothing in
them is from a real company's vault.
