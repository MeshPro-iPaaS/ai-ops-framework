# Pre-built vaults

One folder per naming scheme. **Copy the contents of one of them** into the person's folder —
all of it, including the hidden `.claude` and `.ops` folders — and the install is done. No
Python, no terminal, nothing to run.

| Folder | Your three executives are called |
|---|---|
| `titles/` | Chief of Staff, AI Operations Lead, Workflow Architect |
| `norse/` | Saga, Völundur, Bragi |
| `friends/` | Monica, Chandler, Ross |
| `kardashian/` | Kourtney, Kim, Khloé |
| `greek/` | Athena, Hephaestus, Hermes |

They are identical apart from the names. See [`../INSTALL.md`](../INSTALL.md).
