# The folder skeleton

One job per folder. The installer creates these and writes a `README.md` into each saying what belongs
in it, so nobody has to guess and no session invents a ninth folder.

| Folder | What belongs in it |
|---|---|
| `00 - Inbox` | Anything not yet filed. Emptied, not stored |
| `01 - Company` | How the organisation works: decisions, roles, workflows, the dashboard |
| `02 - Work` | The things you are actually doing — projects, initiatives |
| `03 - People` | Colleagues, customers, partners: whoever you keep a record about |
| `04 - Knowledge` | Reference material that is true regardless of what you are doing this week |
| `05 - Operations` | The generated picture, the logs, the lists of what is waiting |
| `06 - Daily` | The day log. Append-only, never a source of truth |
| `_Templates` | The shapes every new note is made from |
